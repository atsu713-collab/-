# 4コマ 002：不安くん、常駐しています

投稿日: 未投稿
形式: 1枚画像（4コマ）／1080×1350
テーマ: 不安の機能（危険察知）と誤報の多さ

## 内容

| コマ | 内容 |
|---|---|
| 1 | 部屋に黒い人型が座っている／どちらさまですか。 |
| 2 | 「不安です」／名乗られても困る。 |
| 3 | 「呼んでないんですけど」「呼ばれてないときも来ます。仕事なので」／通勤してくるな。 |
| 4 | 「危険がないか、見張る係です」／まじめに働いていた。※ただし、ほぼ誤報です |

## ねらい

不安を敵ではなく「精度の低い真面目な従業員」として描いています。
笑う対象が本人ではなく現象の方を向くので、落ち込んでいる人が読んでも刺さりません。

## 作り方

`source.html` を Chromium でスクリーンショットして書き出し。

```
chromium --headless --no-sandbox --window-size=1080,1350 \
  --default-background-color=FFF2EBE3 \
  --screenshot=image.png file://$(pwd)/source.html
```

## 作画メモ

- 不安くんは黒いシルエット（目だけ白）。表情を持たせないほどシュールになる
- 吹き出しの尻尾は必ず話者を指す。左右を間違えると読めなくなる
- 吹き出しとキャラを重ねない。SVGは後に書いた要素が上に乗る
- コマの外に置いた文字は書き出し時に描画されないことがある。必ず `.panel` の内側に置く
