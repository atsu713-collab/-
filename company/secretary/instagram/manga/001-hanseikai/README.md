## 投稿手順

1枚画像なのでカルーセルの手順は不要です。通常の投稿で `image.png` を選び、
縦横比を「全体表示」にしてから、`caption.txt` を貼るだけです。

## 作り方

`source.html` を Chromium でスクリーンショットして書き出しています。

```
chromium --headless --no-sandbox --window-size=1080,1350 \
  --default-background-color=FFF2EBE3 \
  --screenshot=image.png file://$(pwd)/source.html
```

絵はSVGの線画です。キャラの顔・布団・吹き出しは `source.html` 内に直接書いてあります。

## 注意

コマの外に置いた文字は書き出し時に描画されないことがあります。
セリフや注記は必ずコマ（`.panel`）の内側に入れてください。
