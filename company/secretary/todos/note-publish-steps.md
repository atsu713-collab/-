# note公開の手順（感染症研修の記録：300円版・運用パック・無料記事）

## STEP 0 手元にそろえるもの
- [ ] 300円版のZip：`通所介護_デイサービス_感染症研修_記録様式_ひな形_記入例付き_Word_PDF_英数字ファイル名版.zip`
- [ ] 運用パックのZip：`通所介護_デイサービス_感染症研修_記録様式_運用パック_記入例3パターン_例文集_受講管理表_Word_PDF_Excel_英数字ファイル名版.zip`
- [ ] 原稿3本：`paid-article-note.md`（300円版）／`paid-article-note-pack.md`（運用パック）／`free-article-infection-training-record.md`（無料記事）
- [ ] URLを貼っておくメモ（スマホのメモ帳など）

## STEP 1 公開前の確認（ここが済んでから公開）
- [ ] 運用パックのExcelを自分のExcelで開き、「記入例_受講管理表」で「未受講」が赤、「要確認」が橙になっているか見る
- [ ] 無料記事の「令和6年4月から義務化」「年1回以上」を最新の通知で確認する
- [ ] 行政書士会の無料相談などで「空欄のひな形の販売」に問題がないか確認する
- [ ] 価格を決める（案：300円／1,980円）
- [ ] 返金の一文を残すか直すか決める

## STEP 2 300円版を公開
- [ ] noteで「投稿」→「テキスト」
- [ ] タイトルを貼る：原稿の1行目（# は外す）
- [ ] 本文を貼る（`<!-- -->` の行は消す）
- [ ] 見出し（## の行）を、noteの見出しボタンで付け直す（## は外す）
- [ ] 「公開に進む」→ 販売設定で「有料」→ 価格を入力
- [ ] 有料エリアの境界線を「ご購入前にお読みください」の下に移動
- [ ] 境界線より下の「（ここにZipファイルを添付）」を消し、その位置で「＋」→「ファイル」→ 300円版のZipを添付
- [ ] 運用パックのURL欄は、いまは空のまま（STEP 4で入れる）
- [ ] ハッシュタグを付ける（例：#通所介護 #デイサービス #感染症対策 #介護記録 #運営基準）
- [ ] 公開 → URLをコピーしてメモに「300円版URL」として貼る

## STEP 3 運用パックを公開
- [ ] STEP 2と同じ手順で、`paid-article-note-pack.md` を貼る
- [ ] 価格を入力（案：1,980円）
- [ ] 境界線より下に運用パックのZipを添付
- [ ] 「（ここに300円版の記事のURLを…）」を消して、300円版URLを1行で貼る
- [ ] 公開 → URLをメモに「運用パックURL」として貼る

## STEP 4 300円版を更新
- [ ] 300円版の記事を編集
- [ ] 「（ここに運用パックの記事のURLを…）」を消して、運用パックURLを1行で貼る
- [ ] 更新

## STEP 5 無料記事を公開
- [ ] `free-article-infection-training-record.md` を貼る（見出しの付け直しはSTEP 2と同じ）
- [ ] 最後の2か所に、300円版URL・運用パックURLをそれぞれ1行で貼る
- [ ] 販売設定は「無料」のまま公開
- [ ] URLをメモに「無料記事URL」として貼る

## STEP 6 有料記事2本に無料記事のURLを貼る
- [ ] 300円版：「（ここに無料記事のURLを…）」に無料記事URLを貼って更新
- [ ] 運用パック：無料記事URLを入れたい場合は「こんな方に」の上あたりに1行で貼って更新（任意）

## STEP 7 買う人の目線で最終確認
- [ ] ログアウトした状態（またはシークレットウィンドウ）で3本を開く
- [ ] 有料記事2本：境界線より下（Zip）が見えていない
- [ ] 記事カード（リンク）を押すと、それぞれ正しい記事に飛ぶ
- [ ] 「（ここに〜）」の書きかけが残っていない
