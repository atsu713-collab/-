# インスタ心理学アカウント 立ち上げ企画書

作成日: 2026-08-28
対象: これから心理学ジャンルで投稿を始める人

---

## 0. 結論（先に3行）

1. **「送信（DMシェア）される投稿」だけを狙う**。2026年のアルゴリズムは、いいねより「友達に送られたか」を3〜5倍重く見ています。
2. **リールで新規を取り、カルーセルで保存とフォローを取る**。役割が違うので、両方を回します。
3. **単発バズを狙わず、シリーズを5本決めて回す**。心理学ジャンルは「次も見たい」が作れた人が勝ちます。

---

## 1. リサーチまとめ

### 1-1. 2026年アルゴリズムの要点

| 項目 | 内容 |
|---|---|
| 最重要シグナル | 視聴時間（Watch Time） / いいね / **送信（Sends＝DMシェア）** の3つ |
| 送信の重み | リールの配信において、いいねの **3〜5倍** の重み |
| リールの役割 | 発見タブ・リールタブで**非フォロワーに強く配信**される。冷たい客層へのリーチ担当 |
| リール尺 | エンゲージメントの最適は **30〜90秒**。3分までは非フォロワーにも配信される |
| カルーセルの役割 | **保存率がリールより高い**。スワイプ率が高いと**投稿48〜72時間後に非フォロワーへ再配信**される |
| エンゲージ率実測 | カルーセル 0.50% / リール 0.48%（2026 Q2・フォロワー基準）＝ほぼ互角。使い分けが正解 |
| 完視聴率 | ほぼ全てに優先する指標。途中離脱＝埋もれる |
| 禁止事項 | TikTok / YouTube Shorts の**透かし入り動画は評価が下がる**。リール専用に書き出すこと |

### 1-2. 心理学ジャンル特有の勝ち筋

- **愛着スタイル（アタッチメント）の図解**は、発見タブの「人間関係」カテゴリで恒常的に伸びる鉄板ネタ。
- 主な視聴者は **25〜44歳**。目的は娯楽ではなく **「自己理解」と「他人の理解」**。
- **「保存」される投稿**＝あとで見返したい実用情報（ハウツー、チェックリスト、言い換え集）。
- **「送信」される投稿**＝「これ、あの人のことだ」と誰かの顔が浮かぶ投稿。心理学ジャンル最大の武器。
- **シリーズ化された投稿**は、単発バズより長期のフォロワー増につながる。
- 作り込んだ映像より、**人間味のある素材＋画面テキスト**のほうが伸びる傾向。

### 1-3. 競合アカウントの3類型

| 型 | 中身 | 強み | 弱み |
|---|---|---|---|
| **図解型** | 4象限・チャート・比較表で見せる | 保存が伸びる。顔出し不要 | 制作に時間がかかる |
| **言葉型** | 刺さる一言＋短い解説 | 量産できる。送信されやすい | 差別化しにくく、埋もれやすい |
| **再現型** | 会話・あるあるを演じて見せる | 完視聴率が高い。ファンがつく | 顔出し・演技のコストが高い |

> **推奨：図解型を主軸に、言葉型を量産の補助に置く。** 顔出しなしで始められて、保存と送信の両方が取れます。

## 2. アカウント設計

### 2-1. コンセプト（穴埋めして1文で決める）

> 「**［誰］** が **［どんな場面］** で困らなくなるように、**［どの心理学領域］** をわかりやすく解説するアカウント」

**推奨の型（3案・上から順におすすめ）**

1. **職場の人間関係 × 心理学** — 悩みが具体的、検索需要が安定、競合が恋愛系より薄い
2. **自己理解 × 愛着スタイル / 認知の歪み** — 保存が最も伸びる。ただし競合は多い
3. **恋愛心理** — 一番伸びやすいが、一番レッドオーシャン。差別化必須

### 2-2. ターゲット

- 25〜44歳、自己理解と対人関係に関心がある層
- 「性格を変えたい」ではなく「**明日の会話をうまくやりたい**」人

### 2-3. プロフィール文テンプレ

```
［肩書き/立場］｜［誰］のための心理学
・毎週◯曜 ［シリーズ名］
・研究ベースでわかりやすく
▼ ［保存必須の1投稿へのリンク or ハイライト誘導］
```

### 2-4. ハイライト構成（開設時に5つだけ）

`はじめまして` / `人間関係` / `自己理解` / `質問箱` / `参考文献`

## 3. 投稿フォーマットの黄金比（週7本）

| 曜日 | 形式 | 目的 |
|---|---|---|
| 月 | リール（30〜60秒） | 新規リーチ |
| 火 | カルーセル（8〜10枚） | 保存・フォロー |
| 水 | リール | 新規リーチ |
| 木 | 言葉型フィード or リール | 送信（DMシェア）狙い |
| 金 | カルーセル | 保存 |
| 土 | リール | 新規リーチ |
| 日 | 休み（ストーリーのみ） | 疲弊防止 |

**ストーリーは毎日1〜3枚。** 質問スタンプ・2択スタンプを毎日1つ。ここで拾った悩みが翌週の投稿ネタになります（ネタ切れ対策として最重要）。

### カルーセルの設計ルール（2026年版）

- **8〜10枚** が最適。スワイプ率が上がり、48〜72時間後の再配信を取りにいける
- 1枚目：問題提起（結論は書かない）
- 2枚目：「当てはまる人、多いです」で自分ごと化
- 3〜8枚目：1枚＝1メッセージ。**文字は1枚20文字以内**
- 9枚目：まとめ（ここが保存ポイント）
- 10枚目：「この話が刺さる人に送ってあげてください」＝送信の明示的な依頼

## 4. 企画：シリーズ5本柱 × ネタ30本

シリーズ名を決めて毎回同じデザインで出すと、「またこれだ」と認識されてフォローに繋がります。

### シリーズ①「言い換え図鑑」（言葉型／量産用・週2）
相手を傷つけない伝え方を、NG→OKの2枚で見せる。**最も送信されやすい形式。**

1. 「なんで？」→「どういう経緯だった？」（責めずに事実を聞く）
2. 「前も言ったよね」→「もう一度すり合わせさせて」
3. 「大丈夫？」→「何を代わろうか？」
4. 「頑張って」→「ここまでよくやってるよ」
5. 「普通は〜」→「私はこう思っていて」（Iメッセージ）
6. 「忙しい？」→「5分もらえますか？」（相手の負担を可視化）

### シリーズ②「関係が壊れる瞬間」（リール／リーチ用・週2）
心理学の実験名を出して、権威性と信頼を作る。

7. 4つの騎士（批判・侮辱・自己弁護・逃避）— ゴットマンの離婚予測研究
8. 返報性の原理 — 先に与えた人が最終的に得をする理由
9. 単純接触効果 — 「話す内容」より「会う回数」
10. 根本的な帰属の誤り — 他人の失敗は性格、自分の失敗は状況のせいにする癖
11. ピーク・エンドの法則 — 別れ際の30秒が印象の8割を決める
12. 社会的手抜き（リンゲルマン効果）— 人が増えるほど手を抜く。会議の設計に効く

### シリーズ③「自分の取扱説明書」（カルーセル／保存用・週1）
最も保存されるシリーズ。愛着スタイルは発見タブの定番。

13. 愛着スタイル4分類（安定・不安・回避・恐れ）を4象限図で
14. 不安型と回避型が惹かれ合って苦しくなる仕組み
15. 認知の歪み10パターン チェックリスト
16. HSP・繊細さと「刺激閾値」の話（※病名断定はしない）
17. インポスター症候群 — 実力があるのに自信が持てない人へ
18. 完璧主義の2種類（自己志向型／社会規定型）とその見分け方

### シリーズ④「今日から使える」（リール／実用・週1）
即実践できる行動を1つだけ渡す。

19. 相手に好かれる相槌「そうなんですね」より強い一言
20. 頼み事が通る「理由をつけるだけ」の実験（コピー機実験・ランガー）
21. 緊張を消す「不安を興奮に言い換える」だけの方法
22. 断り方3ステップ（感謝→事実→代替案）
23. 会話が続かない人のための「深掘り質問」5つ
24. 怒りが来たときの6秒ルールの正しい使い方

### シリーズ⑤「よくある誤解」（リール／差別化・隔週）
**通俗心理学を正す枠。これがこのアカウントの信頼性を作る最大の武器です。**

25. メラビアンの法則「見た目が9割」は誤用です
26. 血液型性格診断に科学的根拠はない
27. 「右脳型・左脳型」は神経科学的に否定されている
28. マズローの欲求5段階は本人が図にしていない
29. 「学習スタイルに合わせると伸びる」は再現されていない
30. サブリミナル効果の元実験は本人が捏造を告白している

## 5. 台本サンプル（そのまま使えます）

### 5-1. リール台本（45秒／シリーズ②）

| 秒数 | 画面テキスト | 話す・補足 |
|---|---|---|
| 0-3 | **「この4つが出たら、その関係は終わりに向かってます」** | 結論を言わずに引く。ここで離脱が決まる |
| 3-8 | 心理学者ゴットマンは、夫婦の会話15分で離婚を約90%予測しました | 数字＋研究者名で信頼を作る |
| 8-16 | ①批判：「また皿洗ってない」ではなく「あなたはいつもだらしない」 | 具体例を必ず入れる |
| 16-24 | ②侮辱：ため息・鼻で笑う。**これが最も強い予測因子** | 一番刺さるところを強調 |
| 24-32 | ③自己弁護：「でも、そっちだって」 | |
| 32-40 | ④逃避（ストーンウォーリング）：黙る・部屋を出る | |
| 40-45 | **「ひとつでも心当たりがあれば、まだ間に合います」** | 突き放さず、希望で終える |

- **キャプション1行目**（リール画面に唯一表示される）：`「侮辱」が一番危険です。`
- **キャプション末尾**：`思い当たる人に、そっと送ってあげてください。`

### 5-2. カルーセル台本（10枚／シリーズ③）

| 枚 | テキスト |
|---|---|
| 1 | なぜ「好きな人ほど、うまくいかない」のか |
| 2 | 心理学では、これを愛着スタイルで説明します |
| 3 | 4つのタイプ（4象限の図：安定／不安／回避／恐れ） |
| 4 | 安定型：不安になっても、言葉にして確認できる |
| 5 | 不安型：見捨てられ不安。連絡がないと責めたくなる |
| 6 | 回避型：近づかれると苦しい。距離を取ることで自分を守る |
| 7 | **不安型と回避型は、惹かれ合います** |
| 8 | 追う→逃げる→もっと追う。相性ではなく、パターンの問題です |
| 9 | 【まとめ】性格ではなく「反応の癖」。癖は変えられます |
| 10 | この話が刺さる人に、そっと送ってください |

## 8. 心理学ジャンルでやってはいけないこと

このジャンルは、間違えるとアカウントごと信用を失います。以下は厳守です。

1. **診断しない。** 「あなたは◯◯障害です」「これはHSPです」は医療行為の領域。「〜という傾向があります」「〜と呼ばれる状態に近いかもしれません」に留めます。
2. **治療・受診の代わりにしない。** 深刻な内容には「専門機関へ」の一言を必ず添えます。
3. **出典を持つ。** 研究者名・実験名を言えないネタは投稿しない。言えるネタは信頼になります。
4. **通俗心理学を無自覚に流さない。** 血液型・右脳左脳・メラビアン・学習スタイル・サブリミナルは、**否定する側の投稿**にしてください（＝シリーズ⑤。これが差別化になります）。
5. **特定の誰かを断罪しない。** 「毒親」「サイコパス」などの強いラベルは、リーチは出ますが読者の人間関係を壊す方向に働きます。使うなら理解のためだけに。
6. **他アプリの透かし入り動画を上げない。** 配信が落ちます。

## 9. 見る数字（最初の30日はこれだけ）

| 指標 | 目安 | 意味 |
|---|---|---|
| **保存率**（保存÷リーチ） | 1%超えたら合格、3%で当たり | ネタの実用性 |
| **送信数**（DMシェア） | リールで50超えたら伸びる合図 | 拡散の起点。最重要 |
| **完視聴率** | 60%以上 | 尺と構成が合っているか |
| フォロワー数 | 最初の1ヶ月は**見なくていい** | 遅れて動く指標 |

伸びなかった投稿は「1枚目」だけを差し替えて再投稿してみてください。中身ではなくフックが原因のことが8割です。
