## フェーズ1：土台（1〜4週目）
- [ ] 週2本ペースで8本すべて投稿（曜日を固定する）
- [ ] 投稿順：⑧→⑤→④→①→③→②→⑥→⑦

- やらない：フォロワー購入、相互フォロー企画、毎日投稿

## フェーズ2：見つけてもらう（5〜8週目）
- [ ] Instagram週2本を継続（新ネタはコメントから拾う）
- [ ] Threads毎日2本（ストック36本を使う）
- [ ] Threadsで毎日5件返信
- [ ] リール週1本（カルーセルを縦動画に）
- [ ] ストーリーズ週3回
- 目標：フォロワー100→400人
- 見る数字：保存数（最重要）／リーチ／プロフィールへのアクセス数
- 保存が多い投稿と同じテーマをもっと作る

## フェーズ3：受け皿（9〜12週目）
- [ ] LINE公式アカウントを無料開設
- [ ] プロフィールにLINEリンクを貼る
- [ ] 登録特典を1つ作る（例：人間関係のしんどさ診断シート／PDF1枚）
- [ ] 投稿の最後に「プロフィールから受け取れます」を追加
- [ ] 自己紹介の投稿を1本つくる
- 目標：フォロワー400→700人／LINE登録30〜50人
- 理由：DMは埋もれる。LINEに来た人は申し込む確率が大きく上がる

## フェーズ4：申し込み（13〜16週目）
- [ ] モニター価格で3〜5名募集（感想をもらう条件で）
- [ ] 告知順：LINE → ストーリーズ → 投稿

- [ ] 実施後に感想をもらう
- [ ] 感想を投稿に載せる
- 目標：申し込み3〜5件／感想3件以上
- 実績ゼロで正規価格の募集はしない。感想3件を集めてから値上げする

## うまくいかないときの見方
- フォロワーが増えない → 1枚目（表紙）が弱い。テーマではなく表紙を変える
- 保存されない → 「今日できること」が入っていない
- プロフィールに来ない → 10枚目の締めが弱い
- LINE登録されない → 特典が「欲しい」と思えていない
※投稿の中身より先に1枚目を疑う

## この4か月でやらないこと
- 毎日投稿（続かない）
- 完璧なデザイン（テンプレの使い回しで十分）
- 他の人と比べる
- フォロワーが少ないうちからの高額商品
