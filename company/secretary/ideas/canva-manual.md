# Canva操作マニュアル（無料プラン／心理学リール）

作成日: 2026-08-29
Webページ版：https://claude.ai/code/artifact/5a774e93-a720-4709-9228-76df3ceafeb3

Canvaを開いた状態で、上から順にそのまま進められる手順書。無料プランだけで完成する。
PART 1 だけ「白紙から作る（ルートA）」「テンプレートから作る（ルートB）」の2ルートがあり、PART 2 以降は共通。
1本目は60〜90分、2本目からは10〜15分。

## 全体の工程

| | やること | 目安 |
|---|---|---|
| PART 1 | 1ページ目をきれいに作る（A：白紙／B：テンプレート） | 30〜45分 |
| PART 2 | 8ページに増やして文章を入れる | 20分 |
| PART 3 | 自動でめくれるようにする | 10分 |
| PART 4 | 動画として書き出す | 10分 |

1日で終わらせなくてよい。PART 1 まででいったん閉じても、次に開けば続きから進められる。

---

## はじめに：どちらのルートで作るか

1ページ目の作り方だけ2通りある。**PART 2 以降はどちらも同じ。**

| | ルートA｜白紙から | ルートB｜テンプレートから |
|---|---|---|
| 1本目の時間 | 30分 | 30〜45分 |
| デザインを考える手間 | 自分で決める | 決まっている |
| 有料素材の除去 | 不要 | **必要**（ここが手間） |
| 他の人とかぶる | かぶらない | かぶることがある |
| 向いている場合 | 文字だけのシンプルな投稿 | レイアウトの引き出しが欲しい |

**いちばんおすすめ：テンプレートを「レイアウトの下敷き」として使い、色とフォントは自分の3色に塗り替える。**
文字の置き方・余白の取り方だけ借りて、見た目は自分のものにする。かぶらず、デザインも悩まず、有料素材も残らない。
→ ルートBの B5 がその作業。

## PART 1・ルートA｜白紙から1ページ目を作る（30分）

### 01. リールサイズのデザインを開く
1. Canvaのホーム、検索窓に「Instagramリール」と入力
2. 「Instagramリール動画（1080 × 1920 px）」をクリック

**テンプレートは使わず白紙のまま進める。**
無料プランではテンプレートに有料素材（王冠マーク）が混ざっていることが多く、最後に書き出せなくなる。
文字だけの投稿なら白紙から作った方が速くてきれい。

### 02. 背景に色を入れる
1. ページの何もないところをクリック
2. 上に出る「背景色」をクリック
3. 「+」（新しいカラーを追加）を押す
4. 色コードを入力 → `F5F1EA`（`#`は不要）

一度入れた色は「ドキュメントの色」としてこのデザイン内に残る。

### 03. 安全なエリアに線を引く
リールは上下にInstagramのボタンが重なる。先に目印を引く（1回引けば全ページに効く）。

1. `ファイル → 設定 → 定規とガイドを表示`
2. 定規からドラッグして線を引く
3. `ファイル → 設定 → ガイドをロック`

| 位置 | 理由 | 数値 |
|---|---|---|
| 上 | ユーザー名などが重なる | 250 px |
| 下 | キャプション・ボタンが重なる | 1470 px |
| 左 | 端の余白 | 120 px |
| 右 | 端の余白 | 960 px |

この四角の内側にだけ文字を置く。ガイド線は書き出した動画には写らない。

### 04. 文字を置く
1. `T` キー（または「テキスト」→「見出しを追加」）
2. 文章を入力
3. フォント検索欄に「Zen Maru Gothic」
4. 文字サイズ **82**
5. 「スペース」→ 行間 **1.6**
6. 「A」（文字色）→「+」→ `2B3A55`

**王冠マーク（👑）付きのフォントは有料。** ついていないものを選ぶ。
代替候補：Noto Sans JP / M PLUS 1p / Zen Kaku Gothic New

### 05. マーカー（下線）を作る
Canvaに蛍光ペン機能はない。**四角形を文字の後ろに置いて作る。**

1. `R` キー（長方形が出る）
2. 強調したい言葉の上に、横長・薄べったい形に変形
3. 高さは文字の3分の1くらい、位置は下寄せ
4. 色をアクセント淡に → `D98E73`
5. 右クリック → `レイヤー → 最背面へ移動`

透明度は下げなくてよい。

**アクセント色の使い分け**
- 淡い方 `D98E73` … マーカー・下線・図形のみ
- 濃い方 `B5623F` … 強調したい文字
- 淡い色を文字に使うと、屋外のスマホで読めなくなる

### 06. デザイン名を変える
1. 画面上のデザイン名をクリック
2. 「心理学リール_テンプレート用」に変更

**この1ページ目が今後ずっと使う資産になる。**

## PART 1・ルートB｜テンプレートから1ページ目を作る（30〜45分）

ルートAの代わりに読む。終わったらそのまま PART 2 に合流する。

### B1. リールサイズで開いてから探す
1. 先に「Instagramリール動画（1080 × 1920 px）」でデザインを作成する
2. 左メニューの `デザイン` タブをクリック
3. 検索窓にキーワードを入れる

**先にサイズを決めてから探す**と、リール用のテンプレートだけが出る。ホーム画面から探すとサイズ違いが混ざる。

| 探したいもの | 検索キーワード |
|---|---|
| 文字中心のシンプルなもの | リール 文字 ／ minimal reel ／ text reel |
| 名言・引用っぽいもの | quote reel ／ 名言 リール |
| 落ち着いた雰囲気 | aesthetic reel ／ beige reel ／ ナチュラル |
| お役立ち・解説もの | tips reel ／ 豆知識 ／ 教育 リール |

### B2. 「無料」で絞り込む ★必ず先に
1. 検索結果の上の `フィルター` をクリック
2. `価格` または `無料` の項目で **「無料」** を選ぶ

ここを飛ばすと後で全部やり直しになる。
なお「無料テンプレート」でも**中の写真や素材だけが有料**のことがある。B4で確認するので、ここでは完璧を求めなくてよい。

### B3. 選ぶときの4つの基準
今回は「読ませる投稿」なので、派手さより**文字の読みやすさ**で選ぶ。

- **複数ページあるもの**（1枚ものだと8ページ作るのが大変）
- **写真が主役でないもの**（写真は有料が多く、文字も読みにくい）
- **文字が大きいもの**（小さい文字のテンプレはそのままだと読めない）
- **装飾が少ないもの**（飾りが多いほど有料素材が混ざる）

動画テンプレート（サムネイルに再生マーク）を選ぶと、**トランジションと表示時間が最初から入っている。** PART 3 の作業が半分になる。

### B4. 有料素材を取り除く ★ルートBで一番時間がかかる
1. テンプレートを適用したら、要素をひとつずつクリックしていく
2. **王冠マーク（👑）**が出るものが有料
3. 下記のとおり差し替える

| 有料だったもの | どうするか |
|---|---|
| 写真・イラスト | **削除する**（今回の投稿には要らない） |
| フォント | 無料の日本語フォントに変更（Zen Maru Gothic など） |
| 飾りの素材 | 削除、または `R` で作った四角や線で代用 |
| アニメーション | 王冠なしの「フェード」に変更 |

**残っていないか確かめる方法**
`共有 → ダウンロード → MP4形式の動画` をいったん押す。
「Proの要素が含まれています」が出なければ取り除けている。出た場合はその画面が該当箇所を教えてくれる。
**文字を入れる前にやる方が早い。**

### B5. 色を自分の3色に塗り替える ★ここが一番効く
テンプレの色のまま使うと「テンプレそのまま」に見える。ここを変えるだけで自分の投稿になる。

1. **背景**：ページの余白をクリック →「背景色」→「+」→ `F5F1EA`
2. **文字**：テキストを選択 →「A」→「+」→ `2B3A55`
3. **飾り・マーカー**：図形を選択 → 色 → `D98E73`

色を変えるとき「このデザイン内のすべての◯◯を変更」が出たら、押すと一括で変わる。

**3色を超えない。** テンプレには5〜6色使われていることがある。使われている色を数えて3色に減らす。色数を減らすほど、やさしく落ち着いた印象になる。

### B6. 文字を入れ替える
1. テキストをダブルクリックして台本の文章に打ち替える
2. 入り切らないときは、**文字サイズを小さくせず改行の位置を変える**
3. それでも入らなければ**台本の方を短くする**

**文字を小さくしない。** ここで小さくすると、スマホで読めない投稿になる。1ページ35文字の上限を守る。

### B7. ガイド線を引いて、名前をつける
1. ルートAの STEP 03 と同じ手順で安全エリアのガイド線を4本引く
2. テンプレの文字が線の外にはみ出していたら内側に移動
3. デザイン名を「心理学リール_テンプレート用」に変更

テンプレは1080×1920で作られているが、**Instagramのボタンが重なる範囲までは考えられていない。** ここは自分で直す必要がある。

→ **ここから PART 2 に進む。以降はルートAと完全に同じ。**
そして**この作業は最初の1回だけ。** 2本目からは複製して文字を差し替えるだけになる。

### 補足：テンプレートを使った投稿は公開していいのか
問題ない。Canvaのテンプレートは**自分のSNS投稿やビジネスに使うことが認められている。**
禁止されているのは、テンプレートそのものを商品として売ったり、素材を配布したりすること。
文章と色を自分のものに変えて投稿するのは通常の使い方。

## PART 2｜8ページに増やして文章を入れる（20分）

### 07. ページを複製する
ページ右上の複製アイコン（または `Ctrl/⌘ + D`）で **8ページ**にする。
ゼロから作らず必ず複製する。文字の位置・サイズ・色がそのまま揃う。

### 08. 台本を流し込む
文字をダブルクリックして打ち替える。マーカーの四角が要らないページは選択して `Delete`。

| ページ | 役割 | 秒数 |
|---|---|---|
| 1 | 表紙（悩みを言い切る） | 2.5 |
| 2 | 共感（あるある） | 4.5 |
| 3 | 命名（それ、◯◯といいます） | 3.5 |
| 4 | 根拠（実験の話） | 5.5 |
| 5 | 理由（あなたのせいじゃない） | 5.0 |
| 6 | 転換（見方が変わる一言） | 4.5 |
| 7 | 一歩（今日できること） | 4.5 |
| 8 | 締め＋保存のお願い | 3.5 |

**1ページ35文字まで。** 入り切らないときは文字を小さくせず、2ページに割る。

## PART 3｜自動でページがめくれるようにする（10分）

### 09. 表示時間を決める
1. 画面下のタイムラインを開く
2. ページのサムネイルを右クリック → `タイミングを表示`
3. 上の表の秒数を入力（サムネイルの端をドラッグでも可）

合計およそ33秒。

### 10. ページの切り替え効果をつける ★これが「自動でめくれる」の正体
1. タイムラインの**ページとページの境目**のマークをクリック
2. `トランジション` → **ディゾルブ**
3. 継続時間 **0.4秒**
4. **「すべてのページに適用」にチェック**

ページごとに違う効果を使うと素人っぽく見える。全ページ同じにする。
「スライド」でもよいが、どちらか一方に統一する。

### 11. 文字の出方をつける（任意）
テキスト選択 → `アニメート` → **フェード**（王冠マークのないもの）。全ページ揃える。
迷ったらつけなくても成立する。

### 12. 通しで見て、声に出して読む
タイムラインの再生ボタンで頭から確認。
- 声に出して読んで間に合うか
- 間に合わなければ +1秒 か 文字を削る
- ガイド線の外に文字がはみ出していないか

ここを飛ばすと、投稿してから「読めなかった」と気づくことになる。

## PART 4｜動画として書き出す（10分）

### 13. 音楽はつけない
Canvaでは**無音のまま**書き出す。音はInstagram側でつける。
- Canvaの無料音源は選べる数が少ない
- Instagramのトレンド音源の方が見てもらえる人数が増える

### 14. MP4でダウンロード
1. `共有 → ダウンロード`
2. ファイルの種類 → **「MP4形式の動画」**
3. 全ページにチェックが入っているか確認
4. ダウンロード

**「Proの要素が含まれています」と出たら**、有料素材が混ざっている。課金は不要。
該当の素材・フォント・アニメーションを探して無料のものに差し替える。

### 15. カバー画像も1枚書き出す
1. もう一度 `共有 → ダウンロード`
2. ファイルの種類 → **PNG**
3. `ページを選択` → 1ページ目だけにチェック
4. ダウンロード

投稿時に「カバーを編集」で選ぶと、プロフィール画面のグリッドが揃う。

### 16. スマホに移す
Googleドライブ / 自分宛てメール / LINEのKeepメモ / AirDrop など。
**ここまでで投稿の一歩手前。**

## 2本目以降（10分）

1. 「心理学リール_テンプレート用」を開く
2. `ファイル → コピーを作成`
3. コピーの方で**文字だけ差し替える**
4. PART 4 の書き出しへ

秒数もトランジションも色もすべて引き継がれる。**元のテンプレート用は編集しない。**

**まとめて3本作る方が続く。** 同じ作業の繰り返しなので頭の切り替えが要らない。
作り終えたらInstagramアプリ側の予約投稿（投稿画面の「詳細設定」→日時指定）で日を分けておける。
Canvaの予約投稿は有料だが、こちらは無料。

## 文字の大きさとフォント

### サイズの目安（1080 × 1920 のとき）

| 用途 | サイズ | 1行に入る日本語 |
|---|---|---|
| 表紙（1ページ目） | 90〜100 | 8〜9文字 |
| 本文（2〜7ページ） | **82** | 約10文字 |
| 情報量が多いページ | 70 | 約12文字 |
| 補足・英字ラベル | 32〜56 | — |

左右の余白を120pxずつ取ると**使える幅は840px**。82なら 840 ÷ 82 で約10文字、これが1行の上限。
1ページ35文字なら3〜4行に収まる。

- **45より小さくしない。** スマホで読めなくなる
- **入らないときはサイズを下げず、文章を削るかページを割る**
- **1ページに2サイズまで。** 大きい方＝強調、普通＝本文

**テキストボックスの角をドラッグして拡大縮小しない。**
サイズが 78.4 のような半端な数値になり、ページごとにバラつく。必ず上部の数値入力欄に直接打ち込む。

行間は「スペース」から **1.6**、文字間隔は **0**。

### フォント（すべて無料）

| フォント | 印象 |
|---|---|
| **Zen Maru Gothic** | 丸くてやさしい（見本で使用） |
| Noto Sans JP | 標準的で一番読みやすい |
| M PLUS Rounded 1c | もっと丸い。かわいい寄り |
| Zen Kaku Gothic New | 角ゴシック。きりっとする |
| Shippori Mincho | 明朝体。落ち着いた雰囲気 |

**丸ゴシックは「やさしさ」、角ゴシックは「信頼感」。** 心理学の投稿なら Zen Maru Gothic か Noto Sans JP が無難。
英字ラベル（SAVE FOR LATER など）は Montserrat / Poppins / Lato などの細めの英字フォントに、文字間隔を少し広げる。

**確認のしかた：** 書き出す前に、画面から50cmほど離れて読めるか見る。画面に近づいて作業していると、いつも大丈夫に見えてしまう。

## よく使うショートカット

| キー | できること |
|---|---|
| `T` | テキストを追加 |
| `R` | 四角形を追加（マーカー用） |

| `Ctrl/⌘ + Z` | ひとつ戻る |

## つまずいたとき

| 症状 | 原因と対処 |
|---|---|
| ダウンロードで課金を求められる | 有料素材（王冠マーク）が混ざっている。課金不要。フォント→アニメーション→素材の順に探して差し替える |
| トランジションが1か所にしかかからない | 「すべてのページに適用」のチェック忘れ |
| 動画にならず画像で落ちてくる | ファイルの種類が PNG/JPG になっている。MP4形式の動画を選ぶ |
| 投稿したら文字が隠れた | 安全エリアの外に文字がある。STEP 03 のガイド線の内側に収める |
| 読み切る前に次に進む | 秒数+1秒 か 文字を減らす。**おすすめは文字を減らす方**（長いと最後まで見られない） |
| 日本語フォントが少ない | フォント検索欄に「日本語」と入れる／フィルタで言語を日本語に絞る |
| 秒数を変える場所がない | 下部のタイムラインが閉じている。下端のバーをクリックして開く |
| 保存容量がいっぱい | 無料は5GBまで。「アップロード」から古いファイルを削除する |
| テンプレを適用したら作っていたページが消えた | 「すべてのページに適用」で既存ページが置き換わった。`Ctrl/⌘ + Z` で戻せる。1ページだけに適用したいときは適用先のページを選んでからクリック |
| テンプレを使ったら他の人と似てしまった | 色とフォントが元のまま。B5のとおり3色を自分の配色に塗り替える |
