# Canva操作マニュアル（無料プラン／心理学リール）

作成日: 2026-08-29
Webページ版：https://claude.ai/code/artifact/5a774e93-a720-4709-9228-76df3ceafeb3

Canvaを開いた状態で、上から順にそのまま進められる手順書。無料プランだけで完成する。
1本目は60〜90分、2本目からは10〜15分。

## 全体の工程

| | やること | 目安 |
|---|---|---|
| PART 1 | 1ページ目をきれいに作る | 30分 |
| PART 2 | 8ページに増やして文章を入れる | 20分 |
| PART 3 | 自動でめくれるようにする | 10分 |
| PART 4 | 動画として書き出す | 10分 |

1日で終わらせなくてよい。PART 1 まででいったん閉じても、次に開けば続きから進められる。

---

## PART 1｜1ページ目をきれいに作る（30分）

### 01. リールサイズのデザインを開く
1. Canvaのホーム、検索窓に「Instagramリール」と入力
2. 「Instagramリール動画（1080 × 1920 px）」をクリック

**テンプレートは使わず白紙のまま進める。**
無料プランではテンプレートに有料素材（王冠マーク）が混ざっていることが多く、最後に書き出せなくなる。
文字だけの投稿なら白紙から作った方が速くてきれい。

### 02. 背景に色を入れる
1. ページの何もないところをクリック
2. 上に出る「背景色」をクリック
3. 「+」（新しいカラーを追加）を押す
4. 色コードを入力 → `F5F1EA`（`#`は不要）

一度入れた色は「ドキュメントの色」としてこのデザイン内に残る。

### 03. 安全なエリアに線を引く
リールは上下にInstagramのボタンが重なる。先に目印を引く（1回引けば全ページに効く）。

1. `ファイル → 設定 → 定規とガイドを表示`
2. 定規からドラッグして線を引く
3. `ファイル → 設定 → ガイドをロック`

| 位置 | 理由 | 数値 |
|---|---|---|
| 上 | ユーザー名などが重なる | 250 px |
| 下 | キャプション・ボタンが重なる | 1470 px |
| 左 | 端の余白 | 120 px |
| 右 | 端の余白 | 960 px |

この四角の内側にだけ文字を置く。ガイド線は書き出した動画には写らない。

### 04. 文字を置く
1. `T` キー（または「テキスト」→「見出しを追加」）
2. 文章を入力
3. フォント検索欄に「Zen Maru Gothic」
4. 文字サイズ **82**
5. 「スペース」→ 行間 **1.6**
6. 「A」（文字色）→「+」→ `2B3A55`

**王冠マーク（👑）付きのフォントは有料。** ついていないものを選ぶ。
代替候補：Noto Sans JP / M PLUS 1p / Zen Kaku Gothic New

### 05. マーカー（下線）を作る
Canvaに蛍光ペン機能はない。**四角形を文字の後ろに置いて作る。**

1. `R` キー（長方形が出る）
2. 強調したい言葉の上に、横長・薄べったい形に変形
3. 高さは文字の3分の1くらい、位置は下寄せ
4. 色をアクセント淡に → `D98E73`
5. 右クリック → `レイヤー → 最背面へ移動`

透明度は下げなくてよい。

**アクセント色の使い分け**
- 淡い方 `D98E73` … マーカー・下線・図形のみ
- 濃い方 `B5623F` … 強調したい文字
- 淡い色を文字に使うと、屋外のスマホで読めなくなる

### 06. デザイン名を変える
1. 画面上のデザイン名をクリック
2. 「心理学リール_テンプレート用」に変更

**この1ページ目が今後ずっと使う資産になる。**

## PART 2｜8ページに増やして文章を入れる（20分）

### 07. ページを複製する
ページ右上の複製アイコン（または `Ctrl/⌘ + D`）で **8ページ**にする。
ゼロから作らず必ず複製する。文字の位置・サイズ・色がそのまま揃う。

### 08. 台本を流し込む
文字をダブルクリックして打ち替える。マーカーの四角が要らないページは選択して `Delete`。

| ページ | 役割 | 秒数 |
|---|---|---|
| 1 | 表紙（悩みを言い切る） | 2.5 |
| 2 | 共感（あるある） | 4.5 |
| 3 | 命名（それ、◯◯といいます） | 3.5 |
| 4 | 根拠（実験の話） | 5.5 |
| 5 | 理由（あなたのせいじゃない） | 5.0 |
| 6 | 転換（見方が変わる一言） | 4.5 |
| 7 | 一歩（今日できること） | 4.5 |
| 8 | 締め＋保存のお願い | 3.5 |

**1ページ35文字まで。** 入り切らないときは文字を小さくせず、2ページに割る。

## PART 3｜自動でページがめくれるようにする（10分）

### 09. 表示時間を決める
1. 画面下のタイムラインを開く
2. ページのサムネイルを右クリック → `タイミングを表示`
3. 上の表の秒数を入力（サムネイルの端をドラッグでも可）

合計およそ33秒。

### 10. ページの切り替え効果をつける ★これが「自動でめくれる」の正体
1. タイムラインの**ページとページの境目**のマークをクリック
2. `トランジション` → **ディゾルブ**
3. 継続時間 **0.4秒**
4. **「すべてのページに適用」にチェック**

ページごとに違う効果を使うと素人っぽく見える。全ページ同じにする。
「スライド」でもよいが、どちらか一方に統一する。

### 11. 文字の出方をつける（任意）
テキスト選択 → `アニメート` → **フェード**（王冠マークのないもの）。全ページ揃える。
迷ったらつけなくても成立する。

### 12. 通しで見て、声に出して読む
タイムラインの再生ボタンで頭から確認。
- 声に出して読んで間に合うか
- 間に合わなければ +1秒 か 文字を削る
- ガイド線の外に文字がはみ出していないか

ここを飛ばすと、投稿してから「読めなかった」と気づくことになる。

## PART 4｜動画として書き出す（10分）

### 13. 音楽はつけない
Canvaでは**無音のまま**書き出す。音はInstagram側でつける。
- Canvaの無料音源は選べる数が少ない
- Instagramのトレンド音源の方が見てもらえる人数が増える

### 14. MP4でダウンロード
1. `共有 → ダウンロード`
2. ファイルの種類 → **「MP4形式の動画」**
3. 全ページにチェックが入っているか確認
4. ダウンロード

**「Proの要素が含まれています」と出たら**、有料素材が混ざっている。課金は不要。
該当の素材・フォント・アニメーションを探して無料のものに差し替える。

### 15. カバー画像も1枚書き出す
1. もう一度 `共有 → ダウンロード`
2. ファイルの種類 → **PNG**
3. `ページを選択` → 1ページ目だけにチェック
4. ダウンロード

投稿時に「カバーを編集」で選ぶと、プロフィール画面のグリッドが揃う。

### 16. スマホに移す
Googleドライブ / 自分宛てメール / LINEのKeepメモ / AirDrop など。
**ここまでで投稿の一歩手前。**

## 2本目以降（10分）

1. 「心理学リール_テンプレート用」を開く
2. `ファイル → コピーを作成`
3. コピーの方で**文字だけ差し替える**
4. PART 4 の書き出しへ

秒数もトランジションも色もすべて引き継がれる。**元のテンプレート用は編集しない。**

**まとめて3本作る方が続く。** 同じ作業の繰り返しなので頭の切り替えが要らない。
作り終えたらInstagramアプリ側の予約投稿（投稿画面の「詳細設定」→日時指定）で日を分けておける。
Canvaの予約投稿は有料だが、こちらは無料。

## よく使うショートカット

| キー | できること |
|---|---|
| `T` | テキストを追加 |
| `R` | 四角形を追加（マーカー用） |
| `Ctrl/⌘ + D` | 選んだものを複製 |
| `Ctrl/⌘ + Z` | ひとつ戻る |
| `Ctrl/⌘ + G` | 複数をまとめる（グループ化） |
| `Delete` | 選んだものを消す |

## つまずいたとき

| 症状 | 原因と対処 |
|---|---|
| ダウンロードで課金を求められる | 有料素材（王冠マーク）が混ざっている。課金不要。フォント→アニメーション→素材の順に探して差し替える |
| トランジションが1か所にしかかからない | 「すべてのページに適用」のチェック忘れ |
| 動画にならず画像で落ちてくる | ファイルの種類が PNG/JPG になっている。MP4形式の動画を選ぶ |
| 投稿したら文字が隠れた | 安全エリアの外に文字がある。STEP 03 のガイド線の内側に収める |
| 読み切る前に次に進む | 秒数+1秒 か 文字を減らす。**おすすめは文字を減らす方**（長いと最後まで見られない） |
| 日本語フォントが少ない | フォント検索欄に「日本語」と入れる／フィルタで言語を日本語に絞る |
| 秒数を変える場所がない | 下部のタイムラインが閉じている。下端のバーをクリックして開く |
| 保存容量がいっぱい | 無料は5GBまで。「アップロード」から古いファイルを削除する |
