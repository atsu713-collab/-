# noteに下書きとして入れる手順

原稿：`note貼り付け用_断っても、ほとんど何も起きなかった.html`（同フォルダ）

---

## 先に知っておくこと（ここでつまずきます）

**noteのエディタは、Markdownをそのまま貼っても変換されません。**
`## 見出し` は「## 見出し」という文字のまま、`**太字**` は「**太字**」のまま表示されます。

さらに、**noteには表（テーブル）を入れる機能がありません。** 原稿にあった3つの表は、貼り付け用ファイルのほうで箇条書きに変換済みです。

なので、.mdファイルは貼らずに、**HTMLファイルのほうを使ってください。**

---

## 手順（10分）

### 1. HTMLファイルをブラウザで開く

`note貼り付け用_断っても、ほとんど何も起きなかった.html` をダブルクリック。
ブラウザで、見出しや太字が反映された状態で表示されます。

### 2. 全選択してコピー

ページ上で `Ctrl + A`（Mac は `⌘ + A`）→ `Ctrl + C`（`⌘ + C`）。

### 3. noteで新規記事を開く

note.com にログイン → 右上の **「投稿」** → **「テキスト」**

### 4. 本文欄に貼り付け

本文の入力欄をクリックして `Ctrl + V`（`⌘ + V`）。

**見出し・太字・引用・箇条書き・区切り線は、そのまま反映されます。**
リッチテキストとして貼られるので、Markdown記号は残りません。

### 5. タイトルを入れる

貼り付けると、本文の先頭に「断っても、ほとんど何も起きなかった」が入っています。
**これを切り取って、上のタイトル欄に移してください。**（本文側は削除）

### 6. 貼り付け後に確認する4点

- [ ] 「【ここから有料パート】」の行がある（あとで有料ラインに置き換えます）
- [ ] 文面の引用（グレーの縦線）が崩れていない
- [ ] 記録シートのコード部分が表示されている
- [ ] 余計な空行が入りすぎていない

### 7. いったん下書き保存

右上の **「下書き保存」**。これで完全に非公開の状態で保存されます。

ここまでで、下書きは完了です。

---

## 有料設定（公開するときに）

### 1. 有料ラインを置く

本文中の **「【ここから有料パート】」の行を削除**して、同じ位置にカーソルを置きます。

エディタ左の **「＋」** → **「有料エリア設定」**（または「有料ライン」）を選択。
線が入った位置から下が、購入者だけに見える範囲になります。

**入れる位置**：「では、実際に何をどう送るのか。ここから先が本編です。」の**すぐ下**。

### 2. 価格を設定

右上の **「公開設定」** → **「販売設定」** で **「有料」** を選択 → **価格** を入力。

- 設定できるのは **100円〜10,000円**
- 今回の推奨は **1,980円**（最初の30部）→ 売れたら **2,980円**

### 3. タグを入れる

同じ公開設定の画面で、最大10個まで。

```
フリーランス／断り方／人間関係／働き方／副業
仕事の悩み／コミュニケーション／個人事業主／テンプレート／note有料記事
```

### 4. 見出し画像

記事上部の画像エリアから設定。白背景＋タイトル＋サブコピーだけでOKです。

### 5. 公開

「公開する」を押して完了。

---

## もし貼り付けがうまくいかなかったら

**症状：太字や見出しが反映されず、記号がそのまま出る**
→ HTMLファイルではなく .md ファイルを貼っています。HTMLのほうを開き直してください。

**症状：貼り付けたら改行がおかしい／詰まって表示される**
→ 一度すべて削除して、章ごと（第1章、第2章……）に分けて貼ると安定します。

**症状：途中で固まる・保存できない**
→ 13,000字あるので、エディタが重くなることがあります。**こまめに下書き保存**してください。

---

## 補足：スマホアプリでも作業できます

noteのアプリからも有料記事の作成・編集・価格設定ができます。
ただし**13,000字の貼り付けはPCのほうが確実**なので、下書き作成まではPC、公開ボタンだけスマホ、という分け方が安全です。
