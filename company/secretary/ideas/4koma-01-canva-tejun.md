# 四コマ #01 Canva組み立て手順

## 手順00：画像をパソコンに保存して整理する

### 保存する
**パソコン**
1. Geminiの画面で画像にカーソルを合わせる
2. 隅に出る「**ダウンロード**」アイコン（下向き矢印）をクリック
   （見つからなければ画像を右クリック →「**名前を付けて画像を保存**」）

**スマホ**
1. 画像をタップして拡大 → **ダウンロード／共有アイコン** →「画像を保存」
2. Googleフォトかドライブ経由でパソコンに移す

⚠️ Canvaの数値入力（X/Y座標）は**パソコンのブラウザ版が確実**。
スマホアプリだと細かい指定がしづらいので、組む作業はパソコンで。

### フォルダと名前を整える（重要）
保存したままだと `Gemini_Generated_Image_a8f3k2.png` のような名前になり、
Canvaにアップロードしたときどれが何コマ目か分からなくなる。

1. デスクトップに「**4koma-01**」フォルダを作る
2. 5枚をそこに入れる
3. 1枚ずつリネーム（ファイル選択 → Windows: `F2` / Mac: `Enter`）

```
00_reference.png   ← 基準画像（次回も使うので必ず残す）
01.png             ← 1コマ目
02.png             ← 2コマ目
03.png             ← 3コマ目
04.png             ← 4コマ目
```

数字を頭に付けると自動で順番に並ぶ。Canvaのアップロード一覧でも並ぶので迷わない。

**`00_reference.png` は消さないこと。** 2本目・3本目も同じキャラで作るときに使う。

## 手順0：組む前に4枚を並べて確認（3分）

パソコンのフォルダで4枚を並べて、この3つだけ見る。

- [ ] **顔が同じ人か**（特に1コマ目と4コマ目。ここが違うと読者が混乱する）
- [ ] **服の色が同じか**（ハル＝白、ノン＝水色）
- [ ] **画面内に文字が入っていないか**（入っていたらそのコマだけ作り直し）

気になるコマがあれば、この段階で作り直す。組んだ後だとやり直しが面倒になる。

## 手順1：Canvaで新規デザインを作る

1. Canvaを開く →「デザインを作成」→「カスタムサイズ」
2. **1080 × 1080 px** を入力して作成

または「デザインを作成」→ 検索窓に「Instagram投稿」→「Instagramの投稿（正方形）」でも同じ 1080×1080 になります。

### 無料プランでの注意
- **カスタムサイズの新規作成は無料で使えます**
- ただし**あとからサイズを変えるのはPro機能**（マジックリサイズ）。必ず最初に 1080×1080 で作り始める
- 素材・フォントは**王冠マークが付いていないもの**だけ使う。付いているとPro素材で、書き出し時に透かしが入る
- PNGダウンロードは無料でできる

## 手順2：背景を生成りにする

白のままより、夏の終わりの空気に合います。

### 方法A：背景色を直接変える（おすすめ）

1. デザイン画面で、**何も置いていないキャンバスの余白部分をクリック**する
2. 画面上部のツールバーに出る**色の四角いタイル**（背景色）をクリック
3. 画面左にカラーパネルが開く
4. パネル上部の「**+**」（新しいカラーを追加）をクリック
5. カラーピッカー下部の入力欄に `FAF6EF` と入力して Enter

`#` は入れても入れなくてもOK。
図形を置かないので、あとでうっかり動かす心配がなく、最背面への移動も不要。

### 方法B：四角形を敷く（方法Aがうまくいかないとき）

1. 左メニュー「**素材**」→ 検索窓に「**四角形**」
2. 四角形をクリックして配置 → 四隅のハンドルでキャンバスの端まで広げる
3. 選択した状態で上部ツールバーの色タイル →「+」→ `FAF6EF`
4. 図形を右クリック →「レイヤー」→「**最背面へ移動**」
   （ショートカット: `Ctrl + Shift + [` / Mac は `⌘ + Shift + [`）

一度追加した色は「使用中のカラー」に残るので、2本目からは選ぶだけ。

## 手順3：4枚を2×2に並べる

### 3-1. アップロードする
1. 左メニューの「**アップロード**」→「**ファイルをアップロード**」
2. 4枚をまとめて選択

### 3-2. キャンバスに置く
3. サムネイルを「**クリック**」して置く（ドラッグしない）

⚠️ ドラッグしてキャンバスの端に落とすと**背景画像になってしまう**ことがある。
そうなったら画像を右クリック →「**背景から切り離す**」で戻せる。

### 3-3. 数値でサイズと位置を決める
4. 画像を**1回クリック**して選択（ダブルクリックはトリミングモードなので注意）
5. 画面上部ツールバー右側の「**位置**」をクリック
6. パネル下部の「**幅 / 高さ / X / Y**」の入力欄に数値を入れる
7. **幅** に `480` → Enter（正方形なら高さも自動で480になる）
8. **X** と **Y** を下の表の通りに入れて、それぞれ Enter

| コマ | X | Y |
|---|---|---|
| 1コマ目 | 40 | 40 |
| 2コマ目 | 560 | 40 |
| 3コマ目 | 40 | 560 |
| 4コマ目 | 560 | 560 |

X = 左からの距離、Y = 上からの距離。基準は**画像の左上の角**。
`40 + 480 + 40 + 480 + 40 = 1080` で、外周も中央の隙間もすべて40pxに揃う。

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| 高さが480にならない | 画像が正方形でない。鍵マーク（縦横比の固定）を外せば両方入力できるが絵が歪む。トリミングで正方形にする方がきれい |
| 「位置」が見つからない | 画像が選択されていない。1回クリックして青い枠が出ているか確認 |
| 数値を入れても動かない | 入力後に **Enter** を押す |
| 画像が動かせない | 背景になっている。右クリック →「背景から切り離す」 |

※ 余白なしでよければ「素材」→「グリッド」の2×2にドラッグすると一発で収まる。
　 今回は40pxの余白を出したいので数値指定を使う。

### 読む順番を迷わせない
2×2は「どっちから読むの？」が起きます。**各コマの左上に小さく ① ② ③ ④ を入れてください。**
- フォントサイズ 24前後、色は濃いグレー（#6B6B6B）
- これがあるだけで、読者が止まらずに最後まで読めます

## 手順4：フキダシとセリフを入れる

1. 「素材」で「吹き出し」と検索 → **白いシンプルな楕円**を選ぶ（4コマとも同じ形で統一）
2. テキストを追加して、下の文をコピペ

```
1コマ目：やることが多すぎて、もう無理…
2コマ目：じゃあ、全部書き出してみて
3コマ目：……あれ
4コマ目：3つしかない
```

### 文字の設定
- フォント：**丸ゴシック系**（Canvaなら「ZEN丸ゴシック」「M PLUS Rounded」など）
- 色：濃いグレー（#3D3D3D）。真っ黒より柔らかく見えます
- サイズ：1〜3コマ目は **28**、**4コマ目だけ 36**

4コマ目を大きくするのがコツです。オチが立ちます。

### 置き方
- フキダシは**キャラの顔にかぶせない**
- 2コマ目はノンのセリフなので、**ノム側（画面の右か左、ノンが立っている方）**に置く
- 誰のセリフか分かるよう、フキダシのしっぽを話している人に向ける

---

## 手順5：書き出す

1. 右上「共有」→「ダウンロード」
2. ファイルの種類：**PNG**
3. 「サイズ」は 1× のままでOK
4. ダウンロード

---

## 手順6：出す前の最終チェック（2分）

スマホで開いて、この3つだけ確認。

- [ ] **文字が読めるか**（スマホの画面で小さすぎないか）
- [ ] **4コマ目でオチが分かるか**（説明がなくても「3つしかなかった」が伝わるか）
- [ ] **順番に迷わないか**（番号が見えているか）

読めれば完成です。細かい粗は気にしなくて大丈夫。1本目は「出すこと」が目的。
