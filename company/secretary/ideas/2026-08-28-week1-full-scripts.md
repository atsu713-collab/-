## 月曜｜① 言い換え図鑑 #01

### 画像テキスト（2枚組）

**1枚目**
```
✕

なんで
やってないの？
```

**2枚目**
```
◯

どこで
詰まってますか？

─────
原因を「人」ではなく
「状況」に向ける聞き方です
```

### キャプション
```
「なんでやってないの？」は、質問の形をした責めです。

聞かれた側は理由を答える前に、
まず自分を守るモードに入ります。
そこから先、内容はほとんど入りません。

心理学に「根本的な帰属の誤り」という言葉があります。
人は、他人の失敗を"性格"のせいにして、
自分の失敗を"状況"のせいにする、という癖のこと。

「なんで」は、その癖がそのまま出た言葉です。

「どこで詰まってますか？」に変えるだけで、
矢印が人から状況に移ります。
責められていないとわかると、人は正直に話します。

言い方を変えただけで、返ってくる情報が変わります。

─────
職場の人間関係を、心理学で。
言い換え図鑑、毎週更新しています。
```

### ハッシュタグ（3〜5個。数を増やしても効果はありません）
`#職場の人間関係 #言い換え #心理学 #働く人と繋がりたい`

## 木曜｜⑦ 傍観者効果（リール50秒）

| 秒 | 画面テキスト | メモ |
|---|---|---|
| 0-3 | **「その会議、あなたのせいで静かなわけじゃないです」** | 責任を外してあげるフック |
| 3-9 | 心理学では「傍観者効果」と呼びます | 用語を先に置く |
| 9-18 | 街で人が倒れたとき、**通行人が多いほど助けが遅れる**という実験があります | |
| 18-27 | 理由は「誰かがやるだろう」。責任が人数で薄まるからです | |
| 27-38 | 会議も同じ。参加者が多いほど、一人あたりの発言責任は薄まります | 職場に接続 |
| 38-47 | 対策は1つ。**「◯◯さん、どう思いますか」と名指しする。** これだけで沈黙は消えます | 対策は1つに絞る |
| 47-50 | 会議を静かにしているのは、人数です | |

### キャプション
```
沈黙の原因は、やる気ではなく人数です。

「うちの会議、誰も発言しない」
「若手のやる気がない」

やる気の問題にされがちですが、
人数の問題である可能性が高いです。

心理学の「傍観者効果」。
街で人が倒れたとき、
通行人が多いほど助けが遅れるという有名な実験があります。

理由は「誰かがやるだろう」。
責任が人数で割り算されるからです。

会議も同じ構造です。
10人いる会議で発言しないことの責任は、10分の1になります。

対策はひとつだけ。
「◯◯さん、どう思いますか」と名指しすること。
指名された瞬間、責任は1分の1に戻ります。

参加人数を減らすのも、同じくらい効きます。

─────
会議が静かなチームの人に、そっと送ってあげてください。
```
`#会議 #傍観者効果 #心理学 #職場の人間関係 #チームマネジメント`

## 金曜｜⑲ 頼み事の通し方（リール40秒）

| 秒 | 画面テキスト | メモ |
|---|---|---|
| 0-3 | **「お願いが通る人」がやっている、たった一言** | 実用フック |
| 3-10 | 有名な実験があります。コピー機に並ぶ列で、順番を譲ってもらう実験 | |
| 10-18 | ①「先にコピーさせてください」→ 承諾 **60%** | 数字を大きく |
| 18-27 | ②「**急いでいるので**、先にコピーさせてください」→ **94%** | ここがピーク |
| 27-36 | 面白いのはここから。③「**コピーを取りたいので**、先にコピーさせてください」→ **93%** | 理由になっていない理由 |
| 36-40 | 人は、理由の**中身**ではなく「理由の**形**」に反応します | 締め |

### キャプション
```
理由は、中身より「形」でした。

心理学者ランガーの有名な実験です。
コピー機の順番を譲ってもらえるか、3パターンで試しました。

①「先にコピーさせてください」→ 60%
②「急いでいるので、先にコピーさせてください」→ 94%
③「コピーを取りたいので、先にコピーさせてください」→ 93%

③、理由になっていませんよね。
コピー機に並んでいるんだから、全員コピーを取りたい。

それでも承諾率はほぼ変わりませんでした。
人は「なぜなら」という形を見た時点で、
自動的に納得モードに入るということです。

だから職場でお願いをするときは、
理由を一言つけるだけで通りやすくなります。

「これ、お願いできますか」より
「◯◯までに出す必要があって、これお願いできますか」

たった一言です。

※ただし、負担の大きい依頼では中身が問われます。
　小さなお願いほど効きます。

─────
今日から使える1手、毎週更新しています。
```
`#心理学 #仕事術 #職場の人間関係 #コミュニケーション`

## 土曜｜⑭ 認知の歪み10個（カルーセル10枚）

| 枚 | テキスト |
|---|---|
| 1 | 仕事で必要以上に落ち込む人の、思考の癖 **10個**<br>（サブ）心理学では「認知の歪み」と呼ばれています |
| 2 | ① **全か無か思考**<br>80点の資料を「失敗」と呼んでしまう |
| 3 | ② **過度の一般化**<br>1回の指摘を「いつも怒られる」に変換する |
| 4 | ③ **心のフィルター**<br>9個の評価より、1個の指摘だけが残る |
| 5 | ④ **心の読みすぎ**<br>既読スルー＝嫌われた、と決めてしまう |
| 6 | ⑤ **べき思考**<br>「先輩なんだから完璧であるべき」 |
| 7 | ⑥ **レッテル貼り**<br>ミスした →「自分は無能だ」に飛躍する |
| 8 | ⑦〜⑩ **拡大解釈・感情的決めつけ・self blame・マイナス化思考** |
| 9 | 【まとめ】<br>落ち込んでいるのは事実ではなく、**変換された解釈**のほうです。<br>癖は、書き出すと弱まります |
| 10 | この話が刺さる人に、そっと送ってください |

### キャプション
```
落ち込んでいるのは、事実ではなく解釈のほうかもしれません。

同じ出来事でも、人によって受け取り方が違います。
その差を作っているのが「認知の歪み」と呼ばれる思考の癖です。

たとえば、資料に1箇所指摘を受けたとき。

・9箇所は褒められたのに、1箇所しか覚えていない（心のフィルター）
・「いつも怒られる」と過去まで塗り替える（過度の一般化）
・「自分は仕事ができない」まで飛躍する（レッテル貼り）

どれも、事実からは離れています。

この癖は、性格ではなく変換のパターンです。
書き出して「あ、いま③だ」と名前をつけられるようになると、
それだけで威力が落ちていきます。

保存して、落ち込んだ日に開いてみてください。

※つらさが続く場合は、ひとりで抱えず専門機関にご相談ください。

─────
働く自分の取扱説明書、毎週更新しています。
```
`#認知の歪み #心理学 #働く人と繋がりたい #メンタルケア #職場の人間関係`
