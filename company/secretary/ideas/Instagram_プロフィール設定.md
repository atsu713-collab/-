# Instagram プロフィール設定

最終更新：2026-09-04

## 前提
- ペンネーム：ここ
- アカウントのゴール：まずはフォロワーを増やす（収益導線は後回し）
- 肩書き：心理カウンセラー（民間資格）
- 載せる仕事：心理カウンセラーのみ（家事代行・ハウスクリーニングは載せない。必要なら別アカウント）
- 趣味：サッカー観戦のみ（1つに絞る）
- アカウント種別：クリエイターアカウント推奨（音源の制限が少ない）

## 名前欄
```
ここ｜人間関係がラクになる心理学
```
※Instagramの検索は名前欄がヒットする。「人間関係」「心理」の2語を必ず入れる

```
人といると、なぜか疲れてしまう人へ

気にしすぎ／断れない／一人反省会
そのしんどさの理由と、
今日できることを1つずつ書いています

心理カウンセラー
⚽️サッカー観戦がすきです

📌保存して、しんどい日に読み返してください
```
※1行目は肩書きではなく「読者の状態」から入る。専門家名乗りを先頭に置くと読者が構えるため

- 家事代行・ハウスクリーニング（客層が違い、フォローの理由がぼやける）
- 「日常も投稿します」（何のアカウントか分からなくなる）
- 趣味3つすべて（1つに絞るほうが印象に残る）
