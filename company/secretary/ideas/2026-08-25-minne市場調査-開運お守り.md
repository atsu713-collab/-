### この時点での読み

**「壁紙」実物含む7,400点以上 vs デジタル限定250点以上** というギャップが重要です。
minneの「壁紙」検索の大半は実物の壁紙（インテリア用シート等）で、**デジタル待ち受け市場そのものはまだ数百点規模＝レッドオーシャンではない**可能性が高いです。
一方で実物お守りは16,292点あり、**実物側のほうが競合は圧倒的に厚い**。

→ 参入順としては **デジタルが先、実物は差別化前提で後**、が合理的です。

## 4. 売れている作品の「型」

実際に露出していた作品タイトルから抽出した共通構造です。

### 4-1. タイトルは検索語の全部盛り

実例（そのまま）:
> 待ち受け スマホ 壁紙 おしゃれ かわいい iphone android サイズ イラスト 縁起 金運 幸運 風水 ひまわり 龍 北欧

> 花と宝石 宝石待ち受け シトリン 守護石 誕生石 星座石 きらきら スマホ壁紙 ロック画面 開運 金運 引き寄せ お洒落 スタイリッシュ かっこいい 【 ダウンロード販売 】 minne_new

構造 = `[用途語] + [デバイス] + [情緒語] + [ご利益語] + [モチーフ] + [テイスト] + 【ダウンロード販売】`

### 4-2. その他の共通点

- **セット販売**：「2点セット（ロック＋ホーム）」「3種セット」
- **複数サイズ同梱のzip**：iPhone / Android 両対応を明記
- **シリーズ機能を使う**：作家ページ内で「スマホ壁紙」シリーズを作り回遊させる
- **ハッシュタグ**：通常5個まで／minne PLUSなら20個まで。`#minne_new` で新着枠に露出
- **権威付け**：「風水師監修」「お坊さんが作る」など第三者性を1行で提示

### 4-3. 参考にすべき先行作家

| 作家 | 特徴 | 学べる点 |
|---|---|---|
| **ハナプラ**（風水師監修の待ち受け） | minne + 自社STORES + note + 自社メディア(hana-pla.com)の多面展開。**2026年4月時点で 11,439人 / 21,975ダウンロード** | 自社メディアで「2026年開運待ち受けランキング」を作りSEO集客 → 販売導線。minne単体で戦っていない |
| アートde開運SHOP by infinity artist NAO | 「minne限定販売」シリーズを設定 | プラットフォーム限定という希少性の作り方 |
| inoriART | 全部盛りタイトル、300円、複数サイズ | 価格と仕様の標準形 |

## 5. あつこさん向け・商品設計の提案

### 5-1. デジタルお守り（先に着手）

**推奨コンセプト：「12ヶ月分の誕生石お守り待ち受け」または「干支12種お守り待ち受け」**

理由：
- シリーズで自動的に12作品作れる＝出品数が稼げる（minne公式は20点以上を推奨）
- 誕生月・干支は**購入者が自分ごと化しやすく、贈り物にもなる**
- 「金龍・赤富士」の激戦区を正面から避けつつ、開運検索には引っかかる

**仕様案**

| 項目 | 内容 |
|---|---|
| 価格 | 単品 **300円** / 12種セット **3,300円** / 3種セット **777円** |
| 同梱 | iPhone用・Android用・ロック画面・ホーム画面・SNSアイコン正方形（計5ファイル） |
| 形式 | zip |
| タイトル型 | `[誕生石名] 守護石 待ち受け スマホ壁紙 ロック画面 ホーム画面 開運 [ご利益] 誕生石 お守り おしゃれ かわいい iphone android【ダウンロード販売】` |
| ハッシュタグ | #待ち受け #スマホ壁紙 #開運 #お守り #minne_new |

### 5-2. 実物お守り（デジタルの反応を見てから）

競合16,292点なので**「袋物のお守り」で真正面から戦わない**。空きが見えるのは以下。

| 案 | 根拠 | 想定価格 |
|---|---|---|
| **A. レジンお守り（キーホルダー型）** | 実例800円、色オーダー対応で差別化されている。制作ハードル低め | 800〜1,200円 |
| **B. 誕生石×お守りの実物版**（デジタルと同一デザイン） | デジタルと世界観を揃えられる。§5-3の核 | 1,200〜1,800円 |
| **C. お守り置き・ミニ神棚** | 「福招きの社」等が展開。**お守り本体より競合が薄い** | 1,500〜3,000円 |
| D. お守りケース | 高評価商品が多い＝需要はあるが既に激戦 | 1,000〜2,000円 |

### 5-3. 一番の差別化：デジタル × 実物のセット

**「実物お守りを買うと、同じデザインの待ち受けが付いてくる」**

- 実物お守り購入者に、同柄の待ち受け画像を同梱（またはDL案内を封入）
- 逆に、待ち受け購入者へ実物お守りを案内
- **minneでは1作品にダウンロード販売と実物を混在できない**ため、2作品を同じ**シリーズ**に並べて回遊させる形が現実的
- 顧客単価：300円 → 1,500円 → 1,800円（セット）へ引き上げられる

これをやっている作家は今回の調査範囲では見つかりませんでした。**空いています。**

### 5-4. タイミング

今は**2026年8月**。干支・年末年始商材は **10月〜12月が山**。
- 2026年の午年ものは今から作っても遅い
- **2027年＝未年（ひつじ）** の準備を今から始めるのが正解
- 誕生石シリーズは通年商材なので、こちらを先に出して土台にする

## 6. リスク・注意事項

| リスク | 内容 | 対策 |
|---|---|---|
| **効果の断定表現** | 「必ず金運が上がる」「効果絶大」は景品表示法・特商法上のリスク | 「〜と言われています」「願いを込めて制作しました」に統一 |
| **神社・寺院名の使用** | 実在の神社名・社紋は商標／権利の問題 | 一般的な意匠（鳥居・龍・富士）に留める |
| **「祈祷済み」表記** | 実際に祈祷していないのに書くと不当表示 | 事実のみ記載。していないなら書かない |
| **生成AI利用** | minneのAI生成作品に関するガイドラインは要確認（今回サイトにアクセスできず未検証） | **出品前に minne 利用規約・ヘルプを必ず確認** |
| **画像素材の権利** | フリー素材でも商用再配布NGのものが多い | 自作 or 商用再配布可のライセンスのみ使用 |
