# デザイン仕様書｜職場の人間関係 × 心理学

作成日: 2026-08-28
関連: `2026-08-28-instagram-workplace-psychology-30posts.md`

> 目的は「かっこよさ」ではなく、**毎回同じ見た目で出して認識させること**と、**スマホで一瞬で読めること**です。
> 迷う要素を消すために、数値まで全部決めてあります。この通りに作れば悩む時間がゼロになります。

---

## 1. カラーパレット（この3色＋1色だけ使う）

| 役割 | 色 | HEX | 使い方 |
|---|---|---|---|
| 背景（ベース） | 濃紺 | `#1B2A41` | 全スライドの背景。心理学ジャンルで「信頼・落ち着き」に振る |
| 文字（メイン） | オフホワイト | `#F5F2EA` | 見出し・本文。純白 `#FFFFFF` は眩しいので使わない |
| アクセント | マスタード | `#E5B25D` | 強調したい**1スライドに1箇所だけ**。下線・囲み・数字 |
| 補助 | グレー | `#8A94A6` | 補足・注釈・出典表記のみ |

**ルール**
- 1投稿で使う色は**4色まで**。それ以上は素人っぽく見えます。
- アクセント色は**1スライド1箇所**。全部強調＝どこも強調されていない、と同じです。
- 赤は使わない（警告色に見え、心理学の落ち着いた印象を壊します）。

**明るいトーンにしたい場合の代替**（どちらか一方に固定。混ぜない）
背景 `#F5F2EA` / 文字 `#2B2B2B` / アクセント `#C0763B` / 補助 `#9A9A9A`

## 2. サイズと安全領域

| 用途 | サイズ | 注意 |
|---|---|---|
| カルーセル | **1080 × 1350 px（4:5）** | 3:4 より縦に長く、フィードの占有面積が最大 |
| リール | **1080 × 1920 px（9:16）** | |
| ストーリー | 1080 × 1920 px | |

**安全領域（ここに文字を置かない）**
- カルーセル：上下左右に **80px** の余白。左右は必ず空ける（スワイプ時に指がかかります）
- リール：**上 250px / 下 450px** は避ける。下はキャプション・いいねボタンで隠れます
- ストーリー：上下 **250px** ずつ避ける

---

## 3. フォントと文字サイズ

**フォント：`Noto Sans JP` の1書体だけ**（Canvaに標準搭載）。
太さで差をつけます。書体を混ぜると一気に素人っぽくなります。

| 用途 | ウェイト | サイズ（1080×1350基準） | 行間 |
|---|---|---|---|
| 表紙のメイン見出し | Black / Bold | **96 px** | 1.4 |
| 表紙のサブコピー | Medium | 44 px | 1.6 |
| 中身の見出し | Bold | 72 px | 1.4 |
| 中身の本文 | Regular | **46 px** | 1.8 |
| 注釈・出典 | Regular | 28 px | 1.6 |

**リールの字幕**：1080×1920 で **62 px / Bold / 白 / 黒フチ 6px**。1画面 **2行まで**。

**文字数ルール（最重要）**
- 表紙の見出し：**20文字以内**。1行が理想、最大2行
- 中身1枚：**60文字以内**
- 1枚＝**1メッセージ**。2つ言いたくなったら2枚に割る

## 4. テンプレート仕様

### 4-1. カルーセル｜表紙（1枚目）

```
┌──────────────────────────┐
│  [余白 80px]                     │
│                                  │
│  ▍職場の心理学              ← 24px の縦ラインバー（マスタード）＋28px 文字
│                                  │
│                                  │
│  仕事で必要以上に          ← 96px Bold
│  落ち込む人の              ← 中央やや上（上から40%の位置）
│  思考の癖10個              ← アクセント色は「10個」だけ
│                                  │
│                                  │
│  心理学では「認知の歪み」  ← 44px Medium・グレー寄り
│  と呼ばれています                │
│                                  │
│                     [→ スワイプ]  ← 右下・28px・矢印アイコン
└──────────────────────────┘
```

- **背景は無地**。写真もイラストも敷かない（文字が読めなくなるのが最大の離脱要因）
- 見出しは**左揃え**。中央揃えは行が揃わず読みにくい
- 右下の「→」は毎回必ず入れる。**スワイプ率が上がると48〜72時間後の再配信対象**になります

### 4-2. カルーセル｜中身（2〜9枚目）

```
┌──────────────────────────┐
│  ① 全か無か思考           ← 72px Bold・番号はアクセント色
│  ─────────               ← 4px の横罫（グレー）
│                                  │
│  80点の資料を              ← 46px Regular
│  「失敗」と呼んでしまう          │
│                                  │
│                                  │
│                          3 / 10  ← 右下・28px・グレー（進捗表示）
└──────────────────────────┘
```

- **ページ番号（3/10）を必ず入れる**。「あと少しで終わる」と見えるとスワイプが続きます
- 上下中央に寄せず、**上から30%の位置**に見出しを固定。全枚で位置を揃えると気持ちよくスワイプできます

### 4-3. カルーセル｜まとめ（9枚目）＋ 送信依頼（10枚目）

- 9枚目：`【まとめ】` を付けて**保存の理由**を作る。ここだけ枠線で囲む
- 10枚目：`この話が刺さる人に、そっと送ってください` を **72px** で1行。装飾なし
  - ここを飾らないのがコツ。急に素の言葉になると人は動きます

### 4-4. 言い換え図鑑（S1）専用フォーマット｜2枚組

```
1枚目                          2枚目
┌────────────┐   ┌────────────┐
│  ✕                 │   │  ◯                 │
│                    │   │                    │
│  なんで            │   │  どこで            │
│  やってないの？    │   │  詰まってますか？  │
│                    │   │                    │
│                    │   │  ─────       │
│  ← 背景を少し暗く  │   │  相手の防御反応が  │
│    (#141F30)       │   │  消える聞き方です  │
└────────────┘   └────────────┘
```

- **✕ と ◯ の位置・サイズを毎回完全に固定**。これが「またこのシリーズだ」の認識を作ります
- 2枚目の背景をわずかに明るくすると、スワイプした瞬間に「解決した感」が出ます

### 4-5. リールの字幕スタイル

- 画面の**上から55%の位置**に固定（下はUIで隠れ、上は顔や図とぶつかる）
- 1画面 **2行まで / 1行15文字以内**
- 強調したい語だけ**マスタード色**に変える。1本のリールで **3回まで**
- 効果音・派手なアニメーションは入れない。**文字の出し方は「パッと出す」だけ**で統一
- **他アプリの透かしが入った動画は絶対に使わない**（配信が落ちます）

## 5. Canvaでの作り方（初期セットアップ 30分）

1. `カスタムサイズ` → 1080 × 1350 で新規作成
2. 背景を `#1B2A41` に。`ブランドキット`（無料でも色は登録可）に上記4色を登録
3. 表紙・中身・まとめ・送信依頼の **4種類のページを作る**
4. そのデザインを **「テンプレート」として複製専用に保存**（毎回このファイルを複製して文字だけ差し替える）
5. リール用に 1080×1920 で同じことをもう1セット
6. 言い換え図鑑用に 2枚組をもう1セット

> **これ以降、デザインを触らない。** 毎回テンプレを複製して**文字だけ差し替え**ます。
> デザインを毎回考えるのが、投稿が続かなくなる二番目の原因です（一番目は在庫切れ）。

## 6. やりがちなNG

| NG | なぜダメか |
|---|---|
| 背景に写真を敷く | 文字が読めない。スマホでは致命的 |
| フォントを2種類以上使う | 統一感が消え、アカウントとして認識されなくなる |
| 1枚に3つ以上のメッセージ | 1つも残らない |
| 全部を太字・全部を強調 | どこも強調されていないのと同じ |
| 表紙に結論を書く | スワイプする理由が消える |
| 毎回デザインを変える | 「またこの人だ」が発生せず、フォローに繋がらない |
| 明朝体で長文 | スマホの小さい表示で潰れる |
