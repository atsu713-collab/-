## 月曜｜③ 言い換え図鑑 #03

### 画像テキスト（2枚組）

**1枚目**
```
✕

大丈夫？
```

**2枚目**
```
◯

どこを
巻き取りましょうか

─────
答えを限定すると、
本音が出ます
```

### キャプション
```
「大丈夫？」は、9割「大丈夫です」で返ってくる質問です。

聞いているほうは心配して聞いている。
でも聞かれたほうからすると、
「大丈夫じゃない」と答えるにはハードルが高すぎます。

・どこまで話していいのかわからない
・仕事ができないと思われそう
・相手も忙しそう

だから、とりあえず「大丈夫です」と言います。
これは本音を隠しているのではなく、
質問が答えにくいだけです。

「どこを巻き取りましょうか」

こう聞かれると、答えるのは"範囲"だけで済みます。
助けを求める、という重い行為をしなくてよくなる。

質問を具体的にするほど、返ってくる情報は正直になります。

心配は、聞き方に出ます。

─────
言い換え図鑑、毎週更新しています。
```
`#職場の人間関係 #言い換え #心理学 #マネジメント`

## 火曜｜⑩ 心理的安全性の誤解（リール50秒）

| 秒 | 画面テキスト | メモ |
|---|---|---|
| 0-3 | **「心理的安全性の高い職場」を、たぶん誤解しています** | 名指しせず刺す |
| 3-10 | 仲がいい。優しい。怒られない。——**全部ちがいます** | 3つ並べて否定 |
| 10-20 | 提唱したエドモンドソンの定義は「**対人リスクを取っても罰されない**と信じられる状態」 | 定義を正確に出す |
| 20-30 | つまり、**言いにくいことを言っても大丈夫**という意味です | 噛み砕く |
| 30-40 | ぬるい職場ではなく、**厳しい指摘が安全にできる職場**のこと | ここが山場 |
| 40-47 | Googleの調査でも、成果の高いチームの最大の要因はこれでした | 権威づけ |
| 47-50 | 優しさではなく、率直さの話です | 締め |

### キャプション
```
ぬるい職場のことではありません。

「心理的安全性を高めよう」
最近よく言われますが、かなり誤解されています。

・みんな仲がいい
・怒られない
・意見を否定されない

どれも違います。

提唱したハーバードのエドモンドソン教授の定義は、
「対人関係のリスクを取っても、罰せられたり
恥をかかされたりしない、とメンバーが信じている状態」。

対人関係のリスクとは、
・わからない、と言うこと
・ミスを報告すること
・反対意見を言うこと

これらを言っても、評価が下がらないと信じられるか。

つまり心理的安全性が高い職場とは、
仲がいい職場ではなく、
**厳しい指摘が安全にできる職場**のことです。

Googleが自社の数百チームを分析した調査でも、
成果の高いチームの最大の要因はこれでした。

優しくすることと、安全にすることは別物です。

─────
会議とチームの心理学、毎週更新しています。
```
`#心理的安全性 #チームマネジメント #心理学 #職場の人間関係`

## 水曜｜④ 言い換え図鑑 #04

### 画像テキスト（2枚組）

**1枚目**
```
✕

普通は
こうしますよね
```

**2枚目**
```
◯

私はこう考えていて

─────
「普通」は、相手を
常識の外に立たせる言葉です
```

### キャプション
```
「普通は」で始まる指摘は、内容が正しくても通りません。

この言葉を使った瞬間、
相手は"常識の外にいる人"に分類されます。

正しさの問題ではなく、立場の問題になる。
そうなると人は、内容ではなく立場を守り始めます。

「普通そうしますよね」
「常識的に考えて」
「みんなそうしてますよ」

どれも、自分の意見を"世間"に代弁させる言い方です。
主語が大きいほど、反発も大きくなります。

「私はこう考えていて」

主語を自分に戻すと、相手は反論する必要がなくなります。
意見と意見が並ぶだけになる。

言いたいことは、何も削っていません。
主語を変えただけです。

─────
言い換え図鑑、毎週更新しています。
```
`#職場の人間関係 #言い換え #心理学 #コミュニケーション`

## 木曜｜⑳ 断り方3ステップ（リール45秒）★今週の保存本命

| 秒 | 画面テキスト | メモ |
|---|---|---|
| 0-3 | **断れない人へ。謝らずに断る、3ステップです** | 「謝らずに」が引っかかる |
| 3-10 | ほとんどの人は「すみません、ちょっと…」から入ります。**これが一番危ない** | |
| 10-16 | 謝ると「交渉の余地がある」と受け取られるからです | 理由を先に |
| 16-25 | ① **感謝**「声をかけてくれてありがとうございます」 | 番号を大きく |
| 25-33 | ② **事実**「今週は◯◯で埋まっています」（感情ではなく予定を言う） | |
| 33-41 | ③ **代替案**「来週なら動けます」 | |
| 41-45 | 断っているのに、関係が良くなる断り方です | 締め |

### キャプション
```
「すみません」から始めると、断りきれません。

断れない人の多くは、謝罪から入ります。
「すみません、ちょっと難しくて…」

でもこれ、相手には
「押せばいけるかも」と聞こえています。
謝罪は、交渉の余地を差し出す言葉だからです。

謝らずに断る3ステップ。

① 感謝
「声をかけてくれてありがとうございます」
断るのは依頼であって、相手ではない、と最初に示す。

② 事実
「今週は◯◯で埋まっています」
「無理そうです」ではなく、予定という事実を置く。
感情は反論できますが、事実は反論できません。

③ 代替案
「来週なら動けます」「Aだけなら今週できます」
関係を切らずに、負荷だけ下げる。

心理学のアサーティブネス（自他を尊重する自己表現）の
考え方に沿った型です。

我慢するでも、攻撃するでもない、第三の選び方があります。

保存して、次に断るときに開いてください。

─────
今日から使える1手、毎週更新しています。
```
`#断り方 #アサーティブ #心理学 #職場の人間関係 #仕事術`

## 金曜｜㉗「学習スタイル」の誤解（リール40秒）

| 秒 | 画面テキスト | メモ |
|---|---|---|
| 0-3 | **「私は目で見るタイプ」——これ、根拠がありません** | 自分ごとの否定から入る |
| 3-11 | 視覚型・聴覚型・体感覚型。研修や勉強法でよく出てきます | |
| 11-21 | でも「**自分のタイプに合わせて学ぶと成績が上がる**」という結果は、ほとんど得られていません | ここが核心 |
| 21-30 | 大規模なレビュー研究でも、この効果は確認されませんでした | |
| 30-36 | 効くのは**学習者のタイプ**ではなく、**内容に合った教え方**のほうです | 代替案を出す |
| 36-40 | 地図は見せる。発音は聞かせる。それだけの話でした | 締め |

### キャプション
```
「私は目で見るタイプなので」

よく聞きますし、私も言っていました。
でも、これを支える根拠はほとんどありません。

視覚型・聴覚型・体感覚型に人を分けて、
そのタイプに合った方法で教えると成績が上がる。
これを「学習スタイル仮説」と言います。

2008年に発表された大規模なレビュー研究で、
この仮説を支持する質の高い実験は、
ほとんど見つかりませんでした。
その後も再現されていません。

ではどうすればいいか。

効くのは「学習者のタイプ」ではなく、
「内容に合った形式」のほうでした。

・地図は、見せる
・発音は、聞かせる
・自転車は、乗らせる

内容によって最適な形が決まっているだけで、
人によって決まっているわけではない。

自分を「◯◯タイプ」と決めると、
合わない方法を試す前に諦めてしまいます。
それが一番もったいないところです。

─────
このアカウントでは、根拠のある話だけを扱います。
```
`#心理学 #学習スタイル #勉強法 #研修 #ビジネス心理学`

## 土曜｜⑬ 燃え尽きの3段階（カルーセル10枚）

| 枚 | テキスト |
|---|---|
| 1 | 燃え尽きは、**やる気がなくなること**ではありません<br>（サブ）心理学が定義する3つの段階 |
| 2 | 提唱者マスラックは、バーンアウトを**3つの要素**で定義しました |
| 3 | ① **情緒的な消耗**<br>働けるが、感情が動かない。休んでも回復しない |
| 4 | ② **脱人格化**<br>相手を「人」ではなく「案件」として扱い始める |
| 5 | ③ **達成感の低下**<br>できているのに、意味を感じられない |
| 6 | 危険なのは順番です。**①のうちは自覚があります** |
| 7 | ②が出ると、**自覚が消えます**。冷たくなった自分を「効率的になった」と解釈するからです |
| 8 | セルフチェック<br>・人の話を聞くのが面倒になった<br>・雑談が減った<br>・「どうでもいい」が口癖になった |
| 9 | 【まとめ】<br>怠けではなく、**消耗の結果**です。<br>意志で戻すものではなく、負荷を下げて戻すものです |
| 10 | 心当たりのある人に、そっと送ってください |

### キャプション
```
燃え尽きは「やる気がなくなること」ではありません。

心理学者マスラックは、バーンアウトを
3つの要素で定義しています。

① 情緒的な消耗
働けるけれど、感情が動かない。
休日に寝ても回復しない。

② 脱人格化
相手を「人」ではなく「案件」として扱い始める。
共感が面倒になり、事務的になる。

③ 達成感の低下
成果は出ているのに、意味を感じられない。

危ないのは、この順番です。

①の段階では、しんどい自覚があります。
でも②に入ると、自覚が消えます。
冷たくなった自分を「効率的になった」
「大人になった」と解釈してしまうからです。

だから周りが先に気づくことが多い。

・人の話を聞くのが面倒になった
・雑談が減った
・「どうでもいい」が増えた

これは怠けではなく、消耗の結果です。
気合いで戻すものではなく、
負荷を下げることでしか戻りません。

※つらい状態が続く場合は、ひとりで抱えず
　産業医や専門機関にご相談ください。

─────
働く自分の取扱説明書、毎週更新しています。
```
`#バーンアウト #働く人と繋がりたい #心理学 #メンタルケア #職場の人間関係`
