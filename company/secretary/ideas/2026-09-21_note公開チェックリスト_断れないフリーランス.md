### 値上げの目安

30部売れた時点、または「もう値上げしていいか」と迷ったら上げる。
note の有料記事は**後から値上げしても、購入済みの人には影響しません。** 先に買った人が損をする仕組みではないので、遠慮しなくて大丈夫です。

値上げするときは、記事冒頭に1行足すと納得感が出ます。

## 4. 見出し画像

文字だけのシンプルな画像で十分です。凝ったデザインより、**サムネで文字が読めること**のほうが効きます。

**推奨レイアウト（Canvaなら5分）**

- 背景：白または薄いグレー1色
- メインコピー（大）：**断っても、ほとんど何も起きなかった**
- サブコピー（小）：断れないフリーランスのための、断り文面47
- 装飾なし。写真もイラストも入れない

サブコピーを入れるのは、タイトルだけでは「何の話か」が分からないためです。タイトルで引いて、サブで説明する役割分担にしています。

**避けたほうがいいもの**：人物のストックフォト（一気に「よくあるビジネス記事」に見えます）、明朝体の縦書き（スマホで読めません）。

## 5. 公開直後の告知文

### X（3案・どれか1つ）

**A：本文の引きをそのまま使う**
```
金曜22時に「すみません、ちょっとだけ直せますか」が来て、
「承知しました」と打って、消して、また打つ。

あれ、断れないのが原因じゃないです。
毎回ゼロから考えてるのが原因です。

断り文面47パターン、まとめました。
```

**B：反転構文（拡散しやすい）**
```
断ったら嫌われる、と思ってた。

実際に断ってみたら、切れた相手は数えるほど。
しかもそのほとんどは、離れてくれてよかった相手でした。

こわかったのは、断ることじゃなくて
「何て送ればいいか分からない」ことだった。
```

**C：失敗談から入る（共感型）**
```
一度、ちゃんと断れたことがあります。

でも30分後、沈黙に耐えられなくて
「お急ぎなら巻き取りますので」って自分から送った。

5分で「お願いします！」が返ってきました。

壊したの、私です。
```

Cがいちばん人柄が出ます。フォロワーが少ないうちはCが効きます。

### Threads（1案）

結論を出さない形が伸びます。
```
「ちょっとだけ直して」って言われて、
断る文章を打っては消して、結局「承知しました」って送った夜のこと、
まだ覚えてる。

あれ、優しさじゃなくて、ただ疲れてただけだったのかも。
```
