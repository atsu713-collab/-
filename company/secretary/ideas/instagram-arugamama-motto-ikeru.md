# Instagram投稿案：「あるがままのあなたでもっといける」

作成日: 2026-08-28
ステータス: 画像制作待ち（文言・キャプションは確定）

## 概要
- テーマ：あるがままのあなたでもっといける
- 伝えたいこと：「変わらなきゃ」ではなく「今のままで進める」。自己否定からのスタートをやめる提案
- 想定ターゲット：がんばっているのに「まだ足りない」と感じている人（副業・フリーランスで動き出した層）
- 形式：カルーセル（8枚）＋キャプション。リール版の台本も下に用意

---

## 詳細

### A. 投稿構成（確定・全6枚／1枚目が4コマ）

**1枚目：4コマ「準備が終わらない」**

| コマ | 絵 | セリフ |
|---|---|---|
| ① | 机に向かってノートを広げる | 準備ができたら、始めよう |
| ② | 3か月後。本が山積み | まだ足りない気がする… |
| ③ | スマホで他の人の投稿を見て驚く | え、あの人もう始めてる…！ |
| ④ | 本の山に背を向けて一歩出る | 完璧に準備できている日は、来なかった。まず、やってみていい。 |

→ フック・共感・体験を1枚で兼ねる

**2枚目（問題提起）**
準備が足りないんじゃない。
「今の自分ではダメ」という前提が、動きを止めています。

**3枚目（転換・この投稿の核）**
うまくいった人は、別人になったわけじゃない。
**今の自分のまま、動いた人**です。

**4枚目（具体）**
・完璧な言葉じゃなくていい → 伝わればいい
・実績が少なくてもいい → 今できることを書けばいい
・向いてないと思ってもいい → やってみないと分からない

**5枚目（メッセージ）**
削るんじゃなくて、活かす。
直すんじゃなくて、使う。
あるがままのあなたは、もう素材が揃っています。

**6枚目（締め・保存導線）**
自分を変えなくていい。
使い方を変えるだけ。
👉 保存して、迷った日に読み返してください

> 8枚版（言葉だけのカルーセル）はgitの履歴に残しています。戻したくなったら言ってください。

### B. キャプション（2案とも採用・用途で使い分け）

**案1：やわらかめ → フィード投稿（カルーセル）のキャプション用**

```
「あるがままのあなたでもっといける」

もっと自信がついたら。
もっと実績ができたら。
もっとちゃんとした自分になれたら。

そう思っているうちは、
いつまでも“準備中”のままになってしまいます。

前に進んでいる人は、
別人に生まれ変わったわけではなくて、
今の自分のまま、動きはじめた人でした。

完璧な言葉じゃなくていい。
実績が少なくてもいい。
向いてないかも、と思ったままでもいい。

自分を変えるんじゃなくて、
今ある自分の使い方を変えるだけ。

あなたはもう、素材が揃っています。

迷った日に読み返せるように、保存しておいてください🕊️

──
あなたは今、何を「足りない」と感じていますか？
よかったらコメントで教えてください。
```

**案2：言い切り型（短く強め）→ リールのキャプション／ストーリーズの再告知用**

```

あるがままのあなたで、もっといけます。

保存して、迷った日に読み返してください。
```

### F. デザイン指定（カルーセル8枚・制作用）

サイズ：1080 × 1080px（正方形）／8枚

**配色**

| 用途 | 色 | HEX |
|---|---|---|
| 背景（1〜7枚目） | 白磁（わずかに緑みのある白） | `#EEF1EC` |
| 本文・見出し | 墨（緑みの黒） | `#22271F` |
| アクセント・8枚目の背景 | 松葉 | `#2F5D4A` |
| 補助テキスト・罫線 | 若竹 | `#7FA08C` |
| 面の塗り分け | 苔（淡） | `#DDE4DA` |

ベージュ＋テラコッタのような“よくある自己啓発投稿”の配色をあえて外し、白磁×深緑で落ち着いた大人の印象にしています。

**書体**

- 見出し：Zen Old Mincho（明朝）— 言葉を主役にする枚は明朝で大きく
- 本文・箇条書き：Zen Kaku Gothic New（ゴシック）
- 小さいラベル（「01 / 08」など）：Zen Kaku Gothic New・字間を広めに

いずれもGoogle Fonts（無料）。Canvaにも同名フォントがあります。

**レイアウトの方針**

- 余白を広く取る（上下左右に約90pxのマージン）
- 1枚に入れる文字は最小限。読ませるのではなく“目に入る”サイズにする
- 各枚の右上に「01 / 08」のページ表記を入れて、最後まで見てもらう
- 8枚目だけ背景を松葉（深緑）に反転させ、保存導線を目立たせる

**プレビュー**

8枚のレイアウトを実物サイズの比率で並べたプレビューページを作成済み。
（ファイル：`company/secretary/ideas/instagram-arugamama-carousel.html`）
