## フィード投稿の手順（月・水・土）

1. Instagram → ＋ → 投稿
2. 画像を**番号順に**選択（順番を間違えると意味が変わります）
3. フィルターはかけない。トリミングもしない（4:5で作ってあります）
4. キャプションの `.txt` を全文コピーして貼り付け
5. 投稿

---

## リールの作り方（火・木・金）

画像は「1枚＝1シーン」で作ってあります。**動画編集アプリで並べるだけ**です。

### CapCut を使う場合（無料・おすすめ）

1. 新規プロジェクト → 画像を**番号順に**すべて読み込む
2. 各画像の表示時間を、台本の秒数に合わせる
   - 目安：1枚あたり **6〜8秒**（文字数の多い枚は長めに）
   - 合計 **40〜50秒** に収める
3. トランジションは**入れない**（切り替えは「パッと」が仕様です）
4. 音楽：Instagramの人気音源から、静かなものを1つ。音量は 10〜20% に下げる
5. **書き出しは 1080×1920 / 30fps**
6. ⚠️ **CapCutの透かし（エンドロール）は必ず削除する**
   　→ 最後のクリップを削除してから書き出し。透かしが入ると配信が落ちます

### さらに簡単にするなら

音声を入れず、**画像をそのままリールにする**でも成立します。
Instagramアプリ内でも、複数画像を選んでリールにできます。
最初の1週間は、まずこれで出してしまうのが正解です。

### キャプションの注意

**1行目がリール画面に唯一表示されます。** `.txt` の1行目をそのまま使ってください。

## 土曜の夜にやること（10分）

インサイトで、各投稿の**保存数**と**送信数**をメモするだけです。

| 指標 | 判断 |
|---|---|
| 保存率（保存 ÷ リーチ） | 1%超え＝合格 / 3%＝当たり |
| 送信数 | リールで50超え＝伸びる合図 |
| 完視聴率 | 60%未満なら**尺が長い**。次は10秒削る |
| フォロワー数 | **今月は見ない** |

**数字が全部低くても、何も変えないでください。** 判断材料には最低2週間必要です。
初週が伸びないのは普通です。ここで手を入れると、何が効いたのか分からなくなります。

## 文言を直したくなったら

`../generate.py` の `build()` の中を書き換えて、以下を実行するだけで画像を作り直せます。

```bash
cd company/secretary/assets
python3 generate.py
```

- テキスト中の `**〜**` はアクセント色（マスタード）になります
- 色・サイズ・余白はすべてファイル冒頭の定数にまとまっています
- フォントは Noto Sans JP（環境変数 `NSJP_DIR` でフォントの場所を指定）
