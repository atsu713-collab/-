# 感染症の予防及びまん延の防止のための研修 記録（通所介護・デイサービス）様式・ひな形・記入例付き

> 対象：通所介護（デイサービス）／使う人：事業所の職員（施設名・職員名は各自で記入）
> 本様式は記録作成の参考用ひな形です。法令適合や監査通過を保証するものではありません（末尾の免責文を必ずお読みください）。

---

## 1. この記録が必要な理由

- 通所介護の運営基準（指定居宅サービス等の事業の人員、設備及び運営に関する基準〔平成11年厚生省令第37号〕の「衛生管理等」の規定）で、感染症の予防及びまん延の防止のための**研修及び訓練を定期的に実施すること**が求められています（令和6年4月1日から義務化）。
- 解釈通知では、研修は**年1回以上**の定期実施と新規採用時の実施が望ましいとされ、**研修の実施内容を記録すること**が必要とされています。この様式はその「研修の実施記録」に対応するものです（訓練の記録は別様式で作成してください）。
- 実際の基準は各自治体の条例・通知で定められるため、条番号・実施回数・記録の保存期間などは**各自治体の通知を確認してください**。

## 4. 提出前の確認ポイント

### 記入漏れ
- [ ] 事業所名・記録作成者・記録作成日が記入されている
- [ ] 実施日・実施時間（開始〜終了）・実施方法が記入されている
- [ ] 研修区分（定期／新規採用時など）にチェックがある
- [ ] 研修内容が「感染症研修」の一言ではなく、扱った項目が具体的に書かれている
- [ ] 講師・進行担当者が記入されている
- [ ] 対象職員数・参加者数が記入され、別表の人数と一致している
- [ ] 欠席者がいる場合、フォローの方法と実施日が書かれている（「後日対応」だけで終わっていない）
- [ ] 理解度の確認方法と結果が記入されている
- [ ] 管理者確認欄に氏名と日付がある
- [ ] 使用資料・参加者名簿など、記載した添付資料が実際に綴じられている
- [ ] 新規採用者がいた年度は、新規採用時の研修の記録があるか確認した
- [ ] 当年度の研修回数が、各自治体の通知で求められる回数を満たしているか確認した

### 不適切な表現・記載
- [ ] 利用者の氏名や病名など、研修記録に不要な個人情報を書いていない（事例は匿名化している）
- [ ] 「特になし」「問題なし」だけで終わる欄がない（何を確認して問題がなかったのかが分かる）
- [ ] 「全員理解した」など、確認方法の裏付けがない断定表現になっていない
- [ ] 実施していない内容・参加していない職員を記録していない（実態と記録が一致している）
- [ ] 日付の前後関係に矛盾がない（実施日より前に記録作成日・管理者確認日がない など）
- [ ] 訂正は修正液等を使わず、二重線と訂正者・訂正日が分かる方法で行っている（事業所のルールがあればそれに従う）
- [ ] 研修記録と訓練記録を混同していない（訓練は別様式で記録している）
- [ ] 保存期間・保存方法について、各自治体の通知を確認した
